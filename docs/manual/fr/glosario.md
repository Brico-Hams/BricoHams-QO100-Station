# Glossaire

| Terme | Signification |
|---|---|
| **ADC / CAN** | Convertisseur analogique-numérique : convertit une tension en nombres à intervalles réguliers. |
| **ADIF** | Format standard d'échange de journaux de trafic radioamateur. |
| **AGC / CAG** | Contrôle automatique de gain. |
| **Aliasing (repliement)** | Repliement des fréquences au-dessus de fs/2 sur les basses fréquences lors de l'échantillonnage. |
| **AWGN** | Bruit blanc gaussien additif. |
| **Balise** | Porteuse de référence du satellite ; BricoHams l'utilise pour mesurer le décalage du LNB. |
| **BER** | Taux d'erreur binaire. |
| **BPSK / QPSK** | Modulation par déplacement de phase à 2 / 4 phases. |
| **BT** | Produit largeur de bande × temps du filtre gaussien de la GFSK. |
| **C/N0** | Rapport porteuse sur densité de bruit, en dB·Hz. |
| **Costas (matrice)** | Motif de tons à autocorrélation nette, utilisé pour la synchronisation. |
| **CP** | Préfixe cyclique en OFDM. |
| **CRC** | Contrôle de redondance cyclique. |
| **dBFS** | Décibels par rapport à la pleine échelle du CAN. |
| **Décimation** | Réduction de la fréquence d'échantillonnage après filtrage. |
| **Eb/N0** | Énergie par bit sur densité de bruit. |
| **EIRP** | Puissance isotrope rayonnée équivalente. |
| **ENOB** | Nombre effectif de bits d'un CAN. |
| **FFT** | Transformée de Fourier rapide. |
| **FI** | Fréquence intermédiaire (ici, ≈ 739,75 MHz après le LNB). |
| **FSK / GFSK** | Modulation par déplacement de fréquence / avec filtre gaussien. |
| **FT8 / FT4** | Modes numériques à créneaux de 15 s / 7,5 s avec LDPC(174,91). |
| **G/T** | Gain d'antenne sur température de système, en dB/K. |
| **GEO** | Orbite géostationnaire. |
| **GPSDO** | Oscillateur asservi par GPS. |
| **I/Q** | Composantes en phase et en quadrature d'un signal complexe. |
| **ISI** | Interférence entre symboles. |
| **LDPC** | Code de contrôle de parité à faible densité. |
| **LLR** | Rapport de vraisemblance logarithmique. |
| **LNB** | Bloc à faible bruit : amplifie et convertit en FI. |
| **LO** | Oscillateur local. |
| **LoTW** | Logbook of The World, service de confirmation de contacts de l'ARRL. |
| **NF / F** | Facteur de bruit (dB / linéaire). |
| **NTP** | Protocole de synchronisation d'horloge par réseau. |
| **OFDM** | Multiplexage par répartition en fréquences orthogonales. |
| **PTT** | Push-to-talk, appuyer pour parler (déclenche l'émission). |
| **PWA** | Application web progressive. |
| **SDR** | Radio logicielle. |
| **SNR** | Rapport signal sur bruit. |
| **TCXO** | Oscillateur à quartz compensé en température. |
| **TOT** | Durée maximale d'émission. |
| **UTC** | Temps universel coordonné. |
| **Zone morte** | Seuil de variation en dessous duquel aucune correction n'est appliquée (2 Hz sur la balise). |

Les marques citées dans ce manuel appartiennent à leurs propriétaires ; elles n'impliquent ni parrainage ni caution de tiers.
