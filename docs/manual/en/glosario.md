# Glossary

| Term | Meaning |
|---|---|
| **ADC** | Analog-to-digital converter: turns voltage into numbers at regular intervals. |
| **ADIF** | Standard interchange format for amateur radio logs. |
| **AGC** | Automatic gain control. |
| **Aliasing** | Folding of frequencies above fs/2 onto lower ones when sampling. |
| **AWGN** | Additive white Gaussian noise. |
| **Beacon** | The satellite's reference carrier; BricoHams uses it to measure the LNB offset. |
| **BER** | Bit error rate. |
| **BPSK / QPSK** | Phase-shift keying with 2 / 4 phases. |
| **BT** | Bandwidth-time product of the GFSK Gaussian filter. |
| **C/N0** | Carrier-to-noise-density ratio, in dB·Hz. |
| **Costas (array)** | Tone pattern with a sharp autocorrelation, used for synchronization. |
| **CP** | Cyclic prefix in OFDM. |
| **CRC** | Cyclic redundancy check. |
| **dBFS** | Decibels relative to the ADC's full scale. |
| **Decimation** | Reduction of the sampling rate after filtering. |
| **Eb/N0** | Energy per bit over noise density. |
| **EIRP** | Equivalent isotropically radiated power. |
| **ENOB** | Effective number of bits of an ADC. |
| **FFT** | Fast Fourier transform. |
| **IF** | Intermediate frequency (here, ≈ 739.75 MHz after the LNB). |
| **FSK / GFSK** | Frequency-shift keying / with a Gaussian filter. |
| **FT8 / FT4** | Digital modes with 15 s / 7.5 s slots using LDPC(174,91). |
| **G/T** | Antenna gain divided by system temperature, in dB/K. |
| **GEO** | Geostationary orbit. |
| **GPSDO** | GPS-disciplined oscillator. |
| **I/Q** | In-phase and quadrature components of a complex signal. |
| **ISI** | Intersymbol interference. |
| **LDPC** | Low-density parity-check code. |
| **LLR** | Log-likelihood ratio. |
| **LNB** | Low-noise block: amplifies and converts to IF. |
| **LO** | Local oscillator. |
| **LoTW** | Logbook of The World, the ARRL's contact confirmation service. |
| **NF / F** | Noise figure (dB / linear). |
| **NTP** | Network clock synchronization protocol. |
| **OFDM** | Orthogonal frequency-division multiplexing. |
| **PTT** | Push to talk (activates transmission). |
| **PWA** | Progressive web app. |
| **SDR** | Software-defined radio. |
| **SNR** | Signal-to-noise ratio. |
| **TCXO** | Temperature-compensated crystal oscillator. |
| **TOT** | Time-out timer (maximum transmission time). |
| **UTC** | Coordinated Universal Time. |
| **Dead zone** | Change threshold below which no correction is applied (2 Hz on the beacon). |
