# Glossário

| Termo | Significado |
|---|---|
| **ADC** | Conversor analógico-digital: converte tensão em números a intervalos regulares. |
| **ADIF** | Formato padrão de intercâmbio de registos de radioamador. |
| **AGC** | Controlo automático de ganho. |
| **Aliasing** | Dobragem de frequências acima de fs/2 sobre as baixas ao amostrar. |
| **AWGN** | Ruído branco gaussiano aditivo. |
| **Baliza** | Portadora de referência do satélite; o BricoHams usa-a para medir o desvio do LNB. |
| **BER** | Taxa de erro de bit. |
| **BPSK / QPSK** | Modulação por desvio de fase de 2 / 4 fases. |
| **BT** | Produto largura de banda por tempo do filtro gaussiano da GFSK. |
| **C/N0** | Relação portadora/densidade de ruído, em dB·Hz. |
| **Costas (matriz)** | Padrão de tons com autocorrelação nítida, usado para sincronismo. |
| **CP** | Prefixo cíclico em OFDM. |
| **CRC** | Verificação de redundância cíclica. |
| **dBFS** | Decibéis relativos à escala plena do ADC. |
| **Dizimação** | Redução da taxa de amostragem após filtragem. |
| **Eb/N0** | Energia por bit sobre densidade de ruído. |
| **EIRP** | Potência isotrópica radiada equivalente. |
| **ENOB** | Número efetivo de bits de um ADC. |
| **FFT** | Transformada rápida de Fourier. |
| **FI** | Frequência intermédia (aqui, ≈ 739,75 MHz após o LNB). |
| **FSK / GFSK** | Modulação por desvio de frequência / com filtro gaussiano. |
| **FT8 / FT4** | Modos digitais de intervalos de 15 s / 7,5 s com LDPC(174,91). |
| **G/T** | Ganho de antena sobre temperatura de sistema, em dB/K. |
| **GEO** | Órbita geoestacionária. |
| **GPSDO** | Oscilador disciplinado por GPS. |
| **I/Q** | Componentes em fase e em quadratura de um sinal complexo. |
| **ISI** | Interferência entre símbolos. |
| **LDPC** | Código de verificação de paridade de baixa densidade. |
| **LLR** | Razão de verosimilhança logarítmica. |
| **LNB** | Bloco de baixo ruído: amplifica e converte para FI. |
| **LO** | Oscilador local. |
| **LoTW** | Logbook of The World, serviço de confirmação de contactos da ARRL. |
| **NF / F** | Figura de ruído (dB / linear). |
| **NTP** | Protocolo de sincronização de relógio por rede. |
| **OFDM** | Multiplexagem por divisão de frequências ortogonais. |
| **PTT** | Premir para falar (ativa a transmissão). |
| **PWA** | Aplicação web progressiva. |
| **SDR** | Rádio definido por software. |
| **SNR** | Relação sinal/ruído. |
| **TCXO** | Oscilador de cristal com compensação de temperatura. |
| **TOT** | Tempo máximo de transmissão. |
| **UTC** | Tempo universal coordenado. |
| **Zona morta** | Limiar de variação abaixo do qual não se aplica uma correção (2 Hz na baliza). |

As marcas citadas neste manual pertencem aos seus proprietários; não implicam apoio nem aval de terceiros.
