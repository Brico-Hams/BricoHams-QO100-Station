# Glosario

| Término | Significado |
|---|---|
| **ADC** | Conversor analógico-digital: convierte tensión en números a intervalos regulares. |
| **ADIF** | Formato estándar de intercambio de registros de radioaficionado. |
| **AGC** | Control automático de ganancia. |
| **Aliasing** | Plegado de frecuencias por encima de fs/2 sobre las bajas al muestrear. |
| **AWGN** | Ruido blanco gaussiano aditivo. |
| **Baliza** | Portadora de referencia del satélite; BricoHams la usa para medir el desvío del LNB. |
| **BER** | Tasa de error de bit. |
| **BPSK / QPSK** | Modulación por desplazamiento de fase de 2 / 4 fases. |
| **BT** | Producto ancho de banda por tiempo del filtro gaussiano de GFSK. |
| **C/N0** | Relación portadora a densidad de ruido, en dB·Hz. |
| **Costas (matriz)** | Patrón de tonos con autocorrelación nítida, usado para sincronismo. |
| **CP** | Prefijo cíclico en OFDM. |
| **CRC** | Comprobación de redundancia cíclica. |
| **dBFS** | Decibelios respecto a la plena escala del ADC. |
| **Diezmado** | Reducción de la tasa de muestreo tras filtrar. |
| **Eb/N0** | Energía por bit sobre densidad de ruido. |
| **EIRP** | Potencia isótropa radiada equivalente. |
| **ENOB** | Número efectivo de bits de un ADC. |
| **FFT** | Transformada rápida de Fourier. |
| **FI** | Frecuencia intermedia (aquí, ≈ 739,75 MHz tras el LNB). |
| **FSK / GFSK** | Modulación por desplazamiento de frecuencia / con filtro gaussiano. |
| **FT8 / FT4** | Modos digitales de franjas de 15 s / 7,5 s con LDPC(174,91). |
| **G/T** | Ganancia de antena entre temperatura de sistema, en dB/K. |
| **GEO** | Órbita geoestacionaria. |
| **GPSDO** | Oscilador disciplinado por GPS. |
| **I/Q** | Componentes en fase y cuadratura de una señal compleja. |
| **ISI** | Interferencia entre símbolos. |
| **LDPC** | Código de comprobación de paridad de baja densidad. |
| **LLR** | Razón de verosimilitud logarítmica. |
| **LNB** | Bloque de bajo ruido: amplifica y convierte a FI. |
| **LO** | Oscilador local. |
| **LoTW** | Logbook of The World, servicio de confirmación de contactos de la ARRL. |
| **NF / F** | Figura de ruido (dB / lineal). |
| **NTP** | Protocolo de sincronización de reloj por red. |
| **OFDM** | Multiplexación por división de frecuencias ortogonales. |
| **PTT** | Pulsar para hablar (activa la transmisión). |
| **PWA** | Aplicación web progresiva. |
| **SDR** | Radio definida por software. |
| **SNR** | Relación señal a ruido. |
| **TCXO** | Oscilador de cristal con compensación de temperatura. |
| **TOT** | Tiempo máximo de transmisión. |
| **UTC** | Tiempo universal coordinado. |
| **Zona muerta** | Umbral de cambio por debajo del cual no se aplica una corrección (2 Hz en la baliza). |

Las marcas citadas en este manual son de sus propietarios; no implican patrocinio ni aval de terceros.
