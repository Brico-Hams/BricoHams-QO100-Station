# 0002. License GPL-3.0-or-later

- **Status:** Accepted
- **Date:** 2026-11-08

## Context
The project controls and is designed to be used with SDRangel (GPL-3.0), may ship an OpenWebRX+ plugin (OpenWebRX+ is AGPL-3.0) and is aimed at the amateur radio community, where openness is the norm.

## Decision
License all project code under GPL-3.0-or-later. List third-party components in `NOTICE.md`. Contributions are accepted under the same terms (DCO sign-off).

## Alternatives considered
- **MIT/Apache-2.0**: permissive, but would let closed forks of a transmitter controller and sits awkwardly with the GPL ecosystem it depends on.
- **GPL-3.0-only**: blocks future upgrade to later GPL versions for no benefit.
- **AGPL-3.0**: the network clause is appropriate for the OpenWebRX+ plugin only (see ADR 0010); for the main program it would add friction for station owners without a clear gain.

## Consequences
- Anyone distributing modified versions must publish the source.
- Dependencies must be GPL-compatible; the proprietary SDR Console cannot be used as a code source.
- The plugin combined with OpenWebRX+ is subject to the AGPL network clause.
